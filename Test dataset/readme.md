The **AVIP dataset** consists of five structural images, a building, a fountain, a symbol, a main gate, and a charger, and the size of the image is (512×512). This dataset was used to verify the performance of GainNet.

This dataset contributes to further highlighting the network's ability to accurately recognize and process complex geometric structures and various patterns.
